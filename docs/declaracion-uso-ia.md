# Declaración de uso de IA

Se utilizó asistencia de IA para analizar defectos, proponer cambios, ampliar
pruebas y redactar documentación. Las decisiones deben defenderse mediante el
código, las pruebas automatizadas y la ejecución manual; no se considera la
salida de la IA como evidencia por sí sola.

El responsable del proyecto debe revisar especialmente sincronización,
contextos, políticas de reinicio, validación YAML, códigos HTTP, build tags y
las diferencias reales entre señales Unix y terminación de procesos Windows.
